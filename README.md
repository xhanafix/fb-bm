# Penjana Salinan Iklan Facebook

Aplikasi web yang berkuasa untuk menjana salinan iklan Facebook yang menarik menggunakan pelbagai pembekal AI (OpenAI, Groq, atau OpenRouter). Alat ini membantu pemasar dan pemilik perniagaan mencipta salinan iklan yang berkesan berdasarkan formula penulisan yang terbukti.

## 🌟 Ciri-ciri

- Sokongan Pelbagai Pembekal AI:
  - OpenAI (GPT-3.5-turbo)
  - Groq (Mixtral-8x7b)
  - OpenRouter (Pelbagai model)
- Jana masalah pelanggan secara automatik berdasarkan produk/perkhidmatan
- Animasi pemuatan interaktif dengan kesan pensel
- 10 formula penulisan yang terbukti
- Dioptimumkan untuk konteks Malaysia
- Antara muka pengguna yang interaktif
- Reka bentuk responsif
- Fungsi salin ke papan keratan

## 🚀 Mula Pantas

1. Lawati aplikasi di [url-penempatan-anda]
2. Pilih pembekal AI pilihan anda:
   - OpenAI: Dapatkan kunci API dari [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
   - Groq: Dapatkan kunci API dari [console.groq.com/keys](https://console.groq.com/keys)
   - OpenRouter: Dapatkan kunci API dari [openrouter.ai/keys](https://openrouter.ai/keys)

3. Masukkan kunci API anda
4. Isikan butiran produk/perkhidmatan anda
5. Dapatkan cadangan masalah pelanggan
6. Pilih formula penulisan dan nada pilihan anda
7. Jana salinan iklan anda
8. Salin dan gunakan dalam iklan Facebook anda
